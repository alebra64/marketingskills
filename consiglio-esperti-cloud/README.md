# Consiglio degli Esperti · Cloud

Applicazione riservata, 9 specialisti AI, sintesi, contraddittorio e fonti marcate con esito reale.

Il fascicolo reale è nella variabile d'ambiente privata `PRIVATE_SEED_ADER`, mai nel repository pubblico. Segreti su Render: `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`, `DATABASE_URL` (da database gestito), `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`.

Il collegio funziona solo con credenziali provider effettive; fonti italiane non ancora integrate via MCP, e alcuni articoli resteranno NON VERIFICATI. L'applicazione non sostituisce un professionista abilitato. La gestione dei lavori in corso è nel processo web e non è resistente ai riavvii. Il database Render gratuito ha scadenza dopo 30 giorni. Il codice non contiene documenti o dati personali dell'utente.
